MAIN MENU:
Point and pull the trigger to select things on the menu
On the customization table, if you hover your hand over a doll and click the right hand grip button, you will become that character
    - There is an "objective marker" that I created to test the functionality of it, that will point you towards the customization table no matter where you look
There is a mirror as well so you can check out how your character looks

GAMEPLAY:
Hit the ball to start the game timer
Pull the trigger on either hand to change the direction of the ball to return back to your hand
When the game timer ends, you can choose to restart the game or return to menu
To access the pause menu:
    - On Vive: use the menu button on either controller
    - On Oculus: On the right hand, use the A button

MAJOR KNOWN ISSUES:
